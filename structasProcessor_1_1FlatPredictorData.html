Detailed Description

Predictor data prepared for the analog scan: a pointer table indexed by [iTime * membersNb + iMem] giving direct access to each contiguous grid, optionally backed by a flattened copy of the whole dataset for better cache locality (candidates close in time then sit close in memory).
